Checkout y Pasarelas de Pago

Este informe reúne el análisis comparativo del proceso de checkout y pago en línea, tomando como caso real la tienda ZARA Guatemala y contrastándolo con una prueba realizada en el ERP Odoo (entorno Demo). A continuación se describe brevemente cada etapa del proceso, el análisis de brechas resultante y las funciones consideradas indispensables para un sistema propio.

1.1. Caso Real – ZARA Guatemala

Responsable: Natali  |  Enfoque: experiencia de pago, variedad de pasarelas, velocidad de compra y emisión inmediata de comprobantes.

Empresa internacional del sector moda con plataforma de comercio electrónico donde los clientes seleccionan productos, realizan el checkout, efectúan el pago y gestionan posteriormente sus pedidos. El análisis se realizó desde la perspectiva del usuario.

1.1.1. Selección del producto y cesta de compra

El proceso comienza cuando el usuario selecciona un producto, elige las características disponibles, como talla, color, y lo agrega a la cesta.

Desde la cesta se pueden revisar los productos seleccionados antes de iniciar formalmente el proceso de checkout. Esta primera etapa permite verificar la información y el precio del producto antes de continuar con la compra.

1.1.2. Checkout como invitado

Una característica importante de la página de ZARA es que permite realizar compras tanto como usuario registrado como en modalidad de invitado. Al usar la modalidad de invitado, el sistema solicita únicamente los datos necesarios para procesar el pedido. Esto reduce la fricción durante el proceso, ya que el consumidor no está obligado a crear una cuenta. Además, ZARA permite guardar los datos de pago para agilizar futuras compras cuando el cliente utiliza las funciones de su cuenta.

1.1.3. Selección del método de entrega

Durante el checkout, el cliente selecciona dónde desea recibir su compra. ZARA Guatemala ofrece principalmente:

  • Envío a una tienda ZARA, sin costo.
  • Envío a domicilio, sujeto al costo y condiciones indicadas durante el checkout.

El sistema presenta al consumidor las alternativas disponibles, el costo y la fecha estimada de entrega antes de finalizar el pedido, integrando las condiciones de entrega dentro del mismo checkout.

1.1.4. Métodos de pago

ZARA Guatemala ofrece diferentes métodos de pago para sus compras en línea. Actualmente se encuentran disponibles:

  • Visa
  • Mastercard
  • American Express
  • Tarjeta Regalo
  • Tarjeta Abono

La variedad de alternativas permite que el consumidor seleccione el método más conveniente. Además, cuando el saldo de una Tarjeta Regalo no es suficiente para cubrir la totalidad de la compra, ZARA permite combinarla con otro método de pago disponible.

1.1.5. Procesamiento, confirmación y seguimiento del pedido

Una vez que el cliente selecciona el método de pago y finaliza la compra, ZARA continúa con el procesamiento del pedido. En compras con tarjeta bancaria, el cobro se efectúa cuando el pedido es enviado; al utilizar una Tarjeta Regalo, el importe se descuenta al finalizar la compra. Después de completar correctamente el pedido, el cliente recibe un correo electrónico de confirmación con la información de su compra.

Posteriormente, ZARA permite consultar el avance de la compra mediante diferentes estados:

Comprado → En curso → En preparación → Enviado → Recogido por transportista → Entregado al cliente

Los usuarios registrados pueden consultar esta información desde su cuenta, mientras que quienes compran como invitados realizan el seguimiento mediante los enlaces incluidos en los correos relacionados con el pedido.

1.2. Prueba en ERP (Odoo Demo)

Se replicó el proceso de checkout y pago dentro del entorno Demo de Odoo, utilizando el proveedor de pago "Demo" para simular una transacción completa sin usar información bancaria real, desde la configuración inicial hasta la confirmación del pedido.

1.2.1. Configuración del proveedor de pago

Odoo permite configurar diferentes proveedores y métodos de pago. Para esta prueba se utilizó el proveedor Demo, que permite simular una transacción sin utilizar información bancaria real.

1.2.2. Carrito y Checkout

Se agregó un producto al carrito y se inició el checkout. Odoo permite visualizar el resumen de la compra e ingresar los datos necesarios del cliente antes de continuar con el pago.

1.2.3. Procesamiento del pago

Se utilizó el proveedor Demo para simular un pago exitoso. Esta funcionalidad permite comprobar cómo Odoo procesa una transacción electrónica sin utilizar una tarjeta o realizar un cargo real.

1.2.4. Confirmación del pedido y facturación

Después del pago exitoso, Odoo confirma automáticamente el pedido y registra la operación dentro del ERP. Esta integración permite relacionar el proceso de compra con ventas y facturación.

1.3. Análisis de Brechas (Gap Analysis)

A partir de las pruebas realizadas, se compararon las principales funcionalidades de ZARA Guatemala con las disponibles en Odoo Demo, enfocándose en el proceso de checkout y pago.

Funcionalidad ZARA Guatemala Odoo Demo Brecha identificada
Checkout Proceso sencillo y orientado al consumidor, con compra como invitado. Cuenta con un checkout funcional y configurable. Odoo requiere mayor personalización para ofrecer una experiencia tan simplificada como ZARA.
Métodos de pago Visa, Mastercard, American Express, Tarjeta Regalo y Tarjeta Abono. Permite configurar diferentes proveedores y métodos de pago. Odoo necesita configurar e integrar las pasarelas específicas que utilizará la empresa.
Procesamiento del pago El proceso está integrado al checkout y depende del método seleccionado. Permite procesar y simular pagos mediante proveedores integrados. Ambos cumplen la función, pero Odoo depende de la configuración del proveedor de pago.
Confirmación y comprobante Envía confirmación electrónica del pedido, pero en Guatemala no permite emitir factura de compras online. Permite relacionar el pedido con ventas y facturación. El sistema propio debe integrar confirmación inmediata y generación de factura o comprobante.

¿Qué funciones son indispensables para nuestro sistema?

De acuerdo con la comparación realizada entre ambas plataformas, se identificaron los requisitos mínimos que debería cumplir un sistema propio de checkout y pago.

Requisitos indispensables identificados: El sistema debería contar con un checkout rápido y sencillo, diferentes métodos de pago, una pasarela segura, confirmación inmediata de la compra y generación automática del comprobante o factura.
