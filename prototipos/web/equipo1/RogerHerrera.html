4. Conciliación Bancaria y Comisiones

Encargado: Roger Yankee de Jesús Herrera Alcántara  —  0901-23-2429

4.1. Caso Real

Estructura de comisiones: el porcentaje descontado varía según el método de pago (crédito, débito, QR, cuotas) y según el plazo de liquidación que el vendedor elige. Ejemplo: crédito 6,29% + IVA vs. débito 3,25% + IVA para cobro inmediato; en el marketplace, el cobro por vender va de 12,05% a 17,51% según la categoría del producto.

Reembolsos y contracargos: el Programa de Protección al Vendedor cubre al comercio ante un contracargo si el producto es tangible y el envío tiene seguimiento válido. El vendedor debe responder con evidencia de entrega dentro de un plazo definido; si no lo hace, pierde el dinero automáticamente. No cubre productos digitales ni envíos sin tracking.

Tiempos de liquidación: el vendedor configura si quiere el dinero disponible de inmediato (mayor comisión) o esperar 14 o 30 días (menor comisión). Un panel de actividad muestra, cobro por cobro, si el dinero ya está disponible o sigue en proceso, insumo clave para conciliar contra el estado de cuenta bancario.

4.3. Análisis de Brechas (Gap Analysis)

Situación actual

Odoo permite registrar facturas, pagos y movimientos bancarios, además de realizar conciliaciones bancarias. Sin embargo, el sistema estándar no representa de forma específica el modelo de comisiones y liquidaciones descrito en el caso real.

Brechas identificadas

  • Comisiones: Odoo no tiene configuradas automáticamente las diferentes tasas según el método de pago (crédito, débito, QR o cuotas).
  • Liquidaciones: no está configurado un flujo específico para manejar pagos disponibles inmediatamente, a 14 días o a 30 días.
  • Contracargos: no existe un proceso específico para controlar automáticamente los contracargos y verificar la evidencia de entrega.
  • Productos digitales: el caso real diferencia entre productos físicos y digitales, mientras que Odoo requiere una configuración adicional para manejar estas condiciones.
  • Conciliación: Odoo sí permite conciliar movimientos bancarios, pero sería necesario configurar cuentas y reglas específicas para identificar automáticamente las comisiones.

Propuesta de mejora

Configurar cuentas contables para las comisiones, reglas de conciliación automática y condiciones de pago según el plazo de liquidación. De esta forma, Odoo podría acercarse al funcionamiento del caso real y reducir el trabajo manual al conciliar los pagos.
