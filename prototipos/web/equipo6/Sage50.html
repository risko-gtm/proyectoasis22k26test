Multi-Moneda

El módulo de Multi-Moneda de Sage 50 permite trabajar con diferentes monedas dentro de una empresa. Esto es útil cuando se realizan pagos a proveedores extranjeros, cobros internacionales o transacciones que necesitan una conversión de moneda.

El sistema permite definir una moneda principal y utilizar otras monedas con su respectivo tipo de cambio. De esta forma se puede registrar el monto original de la operación y también su equivalente en la moneda principal.

Aspectos que podemos implementar:

  • Manejo de Quetzales y Dólares.
  • Definir una moneda principal.
  • Registrar el tipo de cambio de cada operación.
  • Mostrar el monto original y su equivalente.
  • Guardar un historial de tipos de cambio.

Estado de Cuentas

El Estado de Cuentas permite consultar los movimientos de las cuentas bancarias de la empresa. Se pueden revisar depósitos, pagos, cheques y otros movimientos, además de consultar el saldo disponible.

Una función importante es la conciliación bancaria, ya que permite comparar los movimientos registrados en Sage 50 con la información proporcionada por el banco. Esto ayuda a encontrar movimientos pendientes o diferencias entre los saldos.

Aspectos que podemos implementar:

  • Consultar los movimientos de una cuenta bancaria.
  • Mostrar ingresos, egresos y saldo disponible.
  • Filtrar movimientos por cuenta y fechas.
  • Identificar movimientos conciliados o pendientes.
  • Comparar el saldo del sistema con el saldo bancario.

Programación de Movimientos

En una empresa existen operaciones que se realizan constantemente, como pagos de alquiler, servicios, cuotas o compras periódicas. Registrar la misma información cada vez puede generar trabajo innecesario y aumentar la posibilidad de cometer errores.

Sage 50 permite manejar transacciones recurrentes, guardando los datos de una operación para utilizarlos nuevamente. Antes de realizar el movimiento, el usuario puede revisar o modificar la información.

Funciones que podrían ser útiles:

  • Crear movimientos semanales, mensuales o anuales.
  • Registrar una fecha de inicio.
  • Definir la próxima fecha de ejecución.
  • Consultar movimientos pendientes.
  • Modificar información antes de confirmar.
  • Agregar recordatorios de pagos y cobros.
  • Mostrar si el movimiento está activo, finalizado o cancelado.
