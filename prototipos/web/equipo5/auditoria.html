Benchmarking - Auditoría y Muestreo

Sistema analizado: SafetyChain

Introducción

Para desarrollar el módulo de Auditoría y Muestreo de una empresa dedicada a la producción de embutidos, se tomó como referencia el sistema SafetyChain. Este sistema está orientado a la gestión de calidad, inocuidad y procesos productivos de la industria de alimentos y bebidas.

1. ¿Qué hace el sistema?

SafetyChain permite digitalizar y centralizar actividades relacionadas con la calidad y seguridad de los alimentos. Permite registrar controles durante la producción y guardar los resultados de las muestras.

Algunos parámetros que se pueden controlar son:

  • Peso
  • Temperatura
  • pH
  • Viscosidad
  • Verificación de etiquetas
  • Inspecciones de producto

2. ¿Qué tecnología utiliza?

SafetyChain utiliza diferentes herramientas para administrar los procesos de calidad:

  • Formularios digitales
  • Dispositivos móviles
  • Dashboards
  • Control Estadístico de Procesos (SPC)
  • Alertas y notificaciones
  • Procesos CAPA

3. ¿Cómo se maneja el proceso?

  1. Identificación del lote.
  2. Realización del muestreo.
  3. Validación de los resultados.
  4. Detección de una no conformidad.
  5. Retención del lote.
  6. Investigación del problema.
  7. Acción correctiva.
  8. Nuevo muestreo.
  9. Decisión sobre el lote.

6. Conclusión

SafetyChain es una buena referencia para desarrollar el módulo de Auditoría y Muestreo, ya que permite controlar la calidad durante la producción, registrar muestras, generar alertas y manejar productos retenidos.

Para una empresa productora de embutidos, un sistema similar ayudaría a mejorar la trazabilidad y permitiría conocer lo ocurrido con cada lote, incluyendo auditorías, muestras, resultados y acciones correctivas.
